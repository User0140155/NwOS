NwOS is loaded by GNU GRUB 2 using the Multiboot2 protocol. GRUB loads the ELF kernel and the boot modules, then transfers control to the NwOS entry code. The kernel entry code performs its own transition to 64-bit long mode and initializes its page tables.

UEFI x86-64

For UEFI boot, firmware starts a GRUB EFI application. On the NwOS installer image the standard fallback path is \EFI\BOOT\BOOTX64.EFI. The installed-system ESP contains a standalone GRUB x86-64 EFI application, /boot/kernel.elf, and a GRUB configuration.

Legacy BIOS

The generated ISO also contains a GRUB BIOS boot image. The current installed-system ESP created by the NwOS installer is UEFI-only; the current Makefile does not create a legacy BIOS boot-area image for installed systems.

Secure Boot

The locally built GRUB EFI application and NwOS test image are not signed for Secure Boot. Disable Secure Boot while testing unless you have arranged signing and key enrollment.
