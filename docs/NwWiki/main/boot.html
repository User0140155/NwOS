NwOS uses the Limine bootloader. Limine hands control to the kernel in 64-bit mode and passes information about memory and the framebuffer, so the same kernel can start from both firmware types.

UEFI

On UEFI machines the firmware loads Limine as an EFI application from the EFI System Partition (ESP), usually from \EFI\BOOT\BOOTX64.EFI. A UEFI start gives the kernel a linear framebuffer straight away.

Legacy BIOS

On legacy BIOS machines the firmware loads the first sector of the drive, which chain-loads the rest of Limine. Limine switches to long mode and sets up the video mode (VBE) before starting the kernel.

Secure Boot

ISO that are not signed will not start while Secure Boot is on. Disable it in the firmware settings, or enroll the key if the release provides one.
