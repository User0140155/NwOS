This guide explains how to get NwOS running: first in a virtual machine (the safest way), then on real hardware.

Requirements

  • An x86-64 CPU (the OS is 64-bit; 32-bit-only CPUs are not supported).
  • If you want 32-bit support, check old versions (Note: they not supporting, legacy-bios only, PS/2 keyboard, cant be launched maybe)
  • UEFI firmware or a legacy BIOS - both are supported through Limine.
  • A display that can be driven through VGA or VBE, see Display.
  • A PS/2 or USB-emulated keyboard, see Keyboard support.

Download

All releases are published on GitHub. Pick the newest one (marked Last on the versions list) and download the ISO attached to it.

Run in a virtual machine

QEMU, legacy BIOS

qemu-system-x86_64 -cdrom NwOS.iso -m 512M

QEMU, UEFI

UEFI mode needs the OVMF firmware (package ovmf on most Linux distributions):

qemu-system-x86_64 -cdrom NwOS.iso -m 512M \
    -drive if=pflash,format=raw,readonly=on,file=/usr/share/OVMF/OVMF_CODE.fd

VirtualBox / VMware

  1. Create a new machine, type Other, version Other/Unknown (64-bit).
  2. Give it at least 128 MB of RAM.
  3. Attach the ISO as an optical drive and start the machine.
  4. For UEFI boot enable EFI in the machine's system settings.

Boot from a USB drive

Warning

Writing an ISO erases the whole target drive. Double-check the device name - a wrong one can destroy your data.

Note that this OS unusable, It made as 'hobby' OS and not full support of real machine, check virtualbox for now

To launch: Write ISO to flash drive/disk with ventoy or rufus, and boot from it

Booting

  1. Insert the drive and reboot.
  2. Open the boot menu (usually F12, F11, Esc or F8).
  3. Choose the USB drive. Entries with a UEFI: prefix boot in UEFI mode, the others in legacy mode.
  4. In the Limine menu select NwOS.
Warning

If Secure Boot is enabled, disable it in the firmware settings unless the ISO is signed - see Boot.

After booting

When the system is up you can write programs in NwC. If the screen stays black or the keyboard does not react, check Troubleshooting.

Also note that this system can not support any driver of your: micro, mouse, keyboard, or other.
