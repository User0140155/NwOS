NwWiki is a set of plain HTML fragments in the docs/NwWiki/main/ folder. The search bar indexes every article listed in main/index.json.

Add an article

  1. Create docs/NwWiki/main/my-article.html. Write only the content — no <html> or <body>. Start sections with <h2>.
  2. Add an entry to main/index.json: 
    { "id": "my-article", "title": "My article", "file": "my-article.html",
  "category": "Help", "summary": "One line description",
  "keywords": ["extra", "search", "words"] }
  3. Open nwWiki.html#my-article. The menu, table of contents and search are updated automatically.

Keys and code

Use <kbd> for keys: Ctrl + Alt + Del, and <pre><code> for code blocks.

Testing locally

Browsers block fetch() on file://, so serve the folder:

cd docs
python3 -m http.server 8000

Then open http://localhost:8000/NwWiki/nwWiki.html.
