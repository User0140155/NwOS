Testing the keyboard in a VM

  • Click inside the QEMU window so it captures the keyboard. Release the mouse/keyboard with Ctrl + Alt + G.
  • With a USB keyboard on a physical machine, enable legacy USB / PS/2 emulation in the firmware setup.
