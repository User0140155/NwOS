Common problems and the first things to try. If nothing helps, open an issue on GitHub with your firmware type (UEFI/legacy), the NwOS version and what you see on screen.

The system does not boot

  • Make sure the image was written in raw mode (dd, or Rufus in DD mode), not just copied onto the drive as a file.
  • Try the other boot entry: UEFI: and plain entries start in different modes, see Boot.
  • Disable Secure Boot.
  • Re-download the image — a damaged download is a frequent cause.

Black screen after the Limine menu

  • Try another resolution in the boot entry, see Display.
  • In QEMU add -vga std; in VirtualBox use the VBoxVGA or VMSVGA controller.
  • On UEFI, try legacy mode (CSM) and the reverse.

Keyboard does not respond

  • In a VM click inside the window first so it captures the input.
  • On real hardware enable legacy USB / PS/2 emulation in the firmware setup, or try a PS/2 keyboard.
  • See Keyboard support.

Boots in a VM but not on real hardware

  • Check the firmware type of the machine and test both boot entries.
  • Update the firmware and reset it to defaults.

Reporting a bug

  1. Note the NwOS version (see versions).
  2. Note UEFI or legacy, the VM or hardware model, and what exactly happens.
  3. Attach a screenshot or a photo of the screen.
