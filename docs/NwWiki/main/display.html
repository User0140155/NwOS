NwOS supports VGA text output and VBE graphics. Which one you get depends on how the system was booted.

VGA text mode

VGA text mode is the classic 80×25 character screen at physical address 0xB8000. It needs almost no setup, which makes it useful for early boot messages and debugging.

Framebuffer

The Multiboot2 framebuffer request asks GRUB for a linear framebuffer. On UEFI, the graphics mode is provided through GOP; on legacy BIOS, GRUB uses the available video backend. The kernel receives the framebuffer address, pitch and resolution in Multiboot2 boot information.

VGA textGRUB framebuffer
Resolution80×25 charactersPixels, e.g. 1024×768
Colours16True colour
DrawingWrite charactersWrite pixels

Choosing a resolution

The requested framebuffer mode is declared in the Multiboot2 header in sys/kernel/kernel_entry.asm. GRUB and the firmware choose a supported mode.

Note

If the requested mode is not available, the bootloader may choose a supported fallback mode.

VirtualBox / QEMU

  • QEMU: use -vga std for a VBE-capable adapter.
  • VirtualBox: pick the VBoxVGA or VMSVGA graphics controller.
