NwOS supports VGA text output and VBE graphics. Which one you get depends on how the system was booted.

VGA text mode

VGA text mode is the classic 80×25 character screen at physical address 0xB8000. It needs almost no setup, which makes it useful for early boot messages and debugging.

VBE framebuffer

VBE (VESA BIOS Extensions) provides a linear framebuffer with a higher resolution and 32-bit colour. The bootloader sets the mode and gives the kernel the framebuffer address, pitch and resolution.

Resolution80×25 charactersPixels, e.g. 1024×768
Colours16True colour

Choosing a resolution

The resolution is chosen by the bootloader. In Limine it is set per boot entry with the resolution option (see the Limine documentation).

resolution: 1024x768x32
Note

If the requested mode is not available, Limine falls back to a mode the hardware supports.

VirtualBox / QEMU

  • QEMU: use -vga std for a VBE-capable adapter.
  • VirtualBox: pick the VBoxVGA or VMSVGA graphics controller.
