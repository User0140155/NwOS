NwC is the programming language built for NwOS. Source files have the .nw extension, the compiler (written in C + nasm) produces .nwo binaries, and those run directly inside the OS. The compiler itself runs inside NwOS.

Hello, NwOS

Create a file hello.nw:

#include <nwc.h>
1A main() {
     nw::out << "Hello, NwOS!\n";
     return 0;
}

Compile and run

The compiler turns hello.nw into hello.nwo, which you then run in the OS.

To compile press 'F5' inside of editor, or execute command:

nwc <FILENAME>.nw -o <FILENAME>.nwo

And then execute .nwo file with

run <FILENAME>.nwo

Language basics

Program structure

  • #include <nwc.h> brings in the standard NwC header.
  • 1A main() is the entry point of the program.
  • return 0; ends the program successfully.

Output

Text is written with the stream nw::out and the << operator:

nw::out << "Text\n";

File types

ExtensionMeaning
.nwNwC source code
.nwoCompiled program that runs inside NwOS
.lnwLow level NwC (not released right now)

Shell program

Advanced NwC functions (input, rect ...)

Lets code shell-program that allows input

#include <nwc.h>
1A main() {
    while (1) {
        nw::out << "Shell\n";
        char buf[64];
        nw::cin >> buf;
        if (strcmp(buf, "help") == 0) {
            nw::out << "help, exit\n";
        }
        else if (strcmp(buf, "exit") == 0) {
            break;
        }
    }
    return 0;
}

Output

Shell

Program wait until input, if input is 'help' then output 'help, exit'

If user inputs 'exit' then program is leaving to OS

This is like C++ syntax

Calculator

We made an calculator that executes with command 'calc' inside of OS!

It placed at sys/apps/calculator.nwo

Lets write it right now

#include <nwc.h>
1A main() {
    nw::out << "Calculator\n";
    nw::out << "Enter first number: ";
    1A first_num
    1A second_num
    nw::cin >> first_num;
    nw::out << "Enter second number: ";
    nw::cin >> second_num;
    nw::out << "Enter operating: ";
    char operation_calc[2];
    nw::cin >> operation_calc;
    if (strcmp(operation_calc, "+") == 0) {
        nw::out << "Result: " << first_num + second_num;
    } else if (strcmp(operation_calc, "-") == 0) {
        nw::out << "Result: " << first_num - second_num;
    } else if (strcmp(operation_calc, "*") == 0) {
        nw::out << "Result: " << first_num * second_num;
    } else if (strcmp(operation_calc, "/") == 0) {
        nw::out << "Result: " << first_num / second_num;
    }
    return 0;
}

Output

Output is default calculator

It asks for first num, second, and operating, checking char operation_calc, and outputs result
