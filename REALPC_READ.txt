To run this OS on a real PC, you need a flash drive and an
ISO file from the GitHub releases

UEFI:

You need to put ISO to the flash drive 
(Rufus or ventoy), then put it into PC,
And run OS (check also safe boot if needed),
Warning: Dont use format disk or raw NwFS
It gonna clear all data on disk, use live boot,
